# ⚽ 足球生涯模拟器 V10.0 (Football Career Simulator V10.0)

本项目是《足球生涯模拟器》的全面重构商业级版本 V10.0。

## 🌟 V10.0 核心特色

1. **暗黑 EA FC / FUT Mobile 极客画风**：
   - 包含金色 FUT 球员卡、暗黑透明玻璃拟态（Glassmorphism）、圆角卡片与精美动画。
   - 彻底解决 8.0 版本的页面频繁刷新与卡顿问题，采用单页应用（SPA）无刷新极速体验。
2. **FIFA FUT 球员卡与球探报告系统**：
   - 包含六大核心属性：`PAC` (速度)、`SHO` (射门)、`PAS` (传球)、`DRI` (盘带)、`DEF` (防守)、`PHY` (身体)。
   - 多人种真实风 SVG 头像生成器（适配亚洲/中国、欧洲、南美、非洲球员）。
   - 权威球探报告（自动判定球风模板，如“梅西型边锋”、“哈兰德型中锋”、“德布劳内型前腰”等，附带特点与潜力预测）。
3. **真实球队与 FC26 规格数据**：
   - 包含中国球队（上海海港、上海申花、北京国安、山东泰山、浙江队等）与欧洲顶级豪门（皇马、巴萨、曼城、拜仁、阿森纳、利物浦、国米等）。
   - 球队分为 S / A / B / C / D 梯队。
4. **按月推进与 5 选项分化事件**：
   - 点击“模拟下个月”，按月推进时间（2026年9月、10月...）。
   - 每次随机事件提供至少 **5 个差异化选项**（高风险高回报、稳健、团队、商业、幽默等）。
5. **概率转盘系统 (Roulette System)**：
   - 特训、突破或关键节点弹出交互式 Canvas 旋转抽签轮盘（绿区普通提升、黄区基因突破、紫区神级蜕变、红区拉伤挫折）。
6. **真实转会市场**：
   - 根据玩家 OVR、年龄、当季表现与声望，实时生成 S~D 级球队的转会邀约与周薪待遇。
7. **荣耀奖杯陈列室**：
   - 可视化陈列世界杯、欧冠、顶级联赛冠军、金球奖、金靴奖、亚洲足球先生等尊贵奖杯。

## 🚀 GitHub & Cloudflare Pages 上传与部署教程

本项目为纯静态 SPA 无刷新结构，**不需要任何复杂的 Node/npm 构建命令行**，非常适合通过 GitHub 提交并自动部署到 Cloudflare Pages。

### 1. 更新至原 GitHub 仓库

解压下载的压缩包后，将所有文件拷贝替换到你的原 GitHub 仓库本地目录（如 `Ethanhui6/zuqiu1`）：

```bash
git add .
git commit -m "feat: 重构升级足球生涯模拟器 V10.0 (FIFA FUT卡片+5选项事件+转盘系统+奖杯陈列室)"
git push origin main
```

### 2. Cloudflare Pages 自动部署设置

如果原项目已绑定 Cloudflare Pages：
- **Build command（构建命令）**：留空（None）
- **Build output directory（输出目录）**：`/` 或 `. `（根目录）

Push 成功后，Cloudflare Pages 会在 10 秒内完成增量覆盖更新，保持原 Cloudflare Pages 网址不变并立即上线 V10.0！
