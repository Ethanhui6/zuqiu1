# ⚽ 足球生涯模拟器 V12.0 Apple Music 拟态重构版 (Football Career Simulator V12.0)

本项目是《足球生涯模拟器》的全新升级 V12.0 重构工程。

## 🍎 V12.0 终极演进与特性

1. **Apple Music 苹果拟态 UI 设计语言**：
   * 采用高毛玻璃透光 (`backdrop-filter: blur(25px)`)、苹果黑色（#000000）、SF Pro 字体排版、高饱和红/金拟态发光（Ambient Glow）卡片。
   * 完美的 iOS 移动端底部/顶部导航与卡片圆角。
2. **Seed 随机种子与 Roguelike 天赋抽卡系统**：
   * 支持自定义输入或生成 Seed 种子（如 `Seed: 20260801`），同种子同决策轨迹完全一致。
   * 15 岁进入青训时可抽取金/紫/蓝高阶品质天赋词条（如“天生领袖”、“钢铁体能怪”、“禁区死角杀手”、“社交牛逼症”）。
3. **退役后的“第二人生”（二次职业生涯）**：
   * 40 岁挂靴后可选择转型成为：
     - 👔 豪门主教练 / 国家队掌门人
     - 🎙️ 顶级体育电视台/自媒体签约解说员
     - 💼 俱乐部主席 / 体坛投资人
     - 🌱 全国青训青训总监
4. **⚽ 懂球圈 / 微博热搜与新闻发布会 (Social Feed)**：
   * 展示全网假弹幕、微博热搜榜、赛后新闻发布会提问与媒体评论。
5. **50+ 成就与终极图鉴墙 (Achievements Gallery)**：
   * 展示所有历史重开解锁的 50+ 项成就与终极称号图鉴。
6. **完全修复 8 处数据不一致与 Bugs**：
   * 国足出场统计与“未进国足”逻辑精准统一。
   * 实际签约俱乐部精确统计 `clubList`。
   * 清白度（Innocence）数值与规则说明明确呈现。
   * 巅峰 OVR 显眼标示（避免误解）。
   * 个人殊荣（金球奖、金靴奖）与团队冠军（世界杯、欧冠）解耦拆分。
   * 出生地与位置特质明示。
   * 节奏模式（逐年/标准/电影）与难度模式（新星/职业/残酷）解耦。
7. **PWA Standalone 支持**：
   * 内置 `manifest.json` 与 Service Worker，可直接一键保存到手机桌面作为独立 iOS App 运行。

## 🚀 GitHub & Cloudflare Pages 部署教程

解压下载的压缩包，将其中的所有文件覆盖到你的原 GitHub 仓库目录（如 `Ethanhui6/zuqiu1`）：

```bash
git add .
git commit -m "feat: 重构升级足球生涯模拟器 V12.0 Apple Music拟态版 (Roguelike天赋+懂球圈+退役二次人生+50+成就墙)"
git push origin main
```

Cloudflare Pages 会在数秒内自动构建发布，原网址保持不变并直接升至 V12.0！
