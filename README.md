# ⚽ 足球生涯模拟器 V14.0 优雅浅色版 (Football Career Simulator V14.0)

本项目是《足球生涯模拟器》的全面重构版本 V14.0。

## 🍎 V14.0 架构与极客重构亮点

1. **优雅 Apple 浅色设计风格 (Light Apple UI)**：
   * 采用 Apple iOS 优雅浅色主题（`#F2F2F7` 背景 + 高冰透毛玻璃 `backdrop-filter: blur(25px)`）。
   * 彻底清理冗余杂乱文字（移除了“V13.0 iOS版”等无用版本角标），一目了然。
   * 六边形属性雷达图（Radar Chart）直观呈现六维数值。
2. **开局角色建模捏脸与引导向导 (Onboarding Wizard)**：
   * 打开网页**自动触发开局引导**，提供 4 步骤交互捏脸向导：
     - **步骤 1**：基础资料（姓名、惯用脚、号码、Seed 种子与 **🎲 随机刷新 Seed 按钮**）
     - **步骤 2**：出身地（明示加成）与球场位置选择
     - **步骤 3**：Roguelike 初始高阶天赋抽卡
     - **步骤 4**：六边形雷达图实时评估与确认
3. **真实世界定位：球员职业人生模拟器**：
   * 重心放在剧情抉择、社会舆论、人际关系、反腐调查、合同谈判与退役二次人生上，而非枯燥反复刷比赛。
   * **球队数据库名规范**：球队中文全称，配有官方原生语言小字标示（如：神户胜利船 `ヴィッセル神戸`、全北现代 `全北 現代 モ图`、皇家马德里 `Real Madrid C.F.`）。
   * **真实阵容角色与租借机制**：依据 OVR 与主帅信任度划分为“核心主力 / 轮换球员 / 边缘替补 / 外租锻炼”，能力不足时会被外租至中下游球队积累经验。
   * **EXP 经验成长系统**：属性改为 EXP 经验条积攒进阶（100 EXP $\rightarrow$ +1 Stat），不再是点击一次直加 1 点。
4. **锁定单次推进（修复“无限点击”Bugs）**：
   * 严格规范流程，每次时间推进后锁定按钮，必须完成剧情选择或比赛结算后解锁，绝不重复结算。
5. **融合三大参考网站全量精华**：
   * **绿茵浮沉版**：中国足球故事叙事、阴阳合同反腐、新闻发布会、懂球圈全网热搜与假弹幕。
   * **足一把版**：离线 Seed 种子系统、47+ 成就图鉴墙、四大核心属性联动。
   * **重生版**：Roguelike 天赋抽卡、40 岁挂靴后的第二人生（转型成为豪门主教练、电视解说员、俱乐部主席或青训总监）。
6. **PWA Standalone 支持**：
   * 内置 `manifest.json` 与 Service Worker，可直接一键保存添加到手机桌面作为独立 iOS App 运行。

解压下载的压缩包，将其中的所有文件覆盖到你的原 GitHub 仓库目录（如 `Ethanhui6/zuqiu1`）：

