# 绿茵浮沉 9.0

一个以“能力成长 → 队内竞争 → 获得出场 → 豪门关注 → 转会与荣誉”为核心的球员生涯模拟器。

## V9.0 核心更新

- Apple 原生应用式信息层级，保留 FC 风格金卡球员信息布局。
- 首页改为单屏核心面板，详细内容进入二级菜单。
- “模拟下个月”统一处理训练、比赛、状态与 2–4 个事件。
- 每个事件固定 5 个策略选择，并进行动态概率抽签。
- 3200 个事件场景，覆盖训练、教练、阵容、媒体、经纪、转会、合同、伤病、家庭、国家队等 16 类。
- 成长由训练重点、出场、评分、年龄、潜力和职业态度共同决定。
- 能力不足会出现未进名单、替补、轮换、下放与租借关注。
- 高等级俱乐部报价由 OVR、声望、联赛等级、教练评价和表现共同解锁。
- 创建球员时，球探报告与位置选择在同一页面。
- 球探报告增加球风模板、潜力、惯用脚、逆足、花式、稳定性、适应能力和伤病风险。
- 现实球员采用 FC 26 风格六维数据；精选关键球员数据已按 EA 官方评分页校准。
- 图片延迟加载、局部更新、无 Service Worker 强缓存，减少手机点击卡顿和整页闪烁。

## 本地目录

`index.html` 必须位于仓库根目录。Cloudflare Pages 配置：

- 框架预设：None
- 构建命令：留空
- 输出目录：`.`

## 更新方式

把本压缩包解压后，将里面的所有文件复制到你 GitHub Desktop 当前仓库文件夹，选择“替换目标中的文件”。不要删除 `.git` 文件夹。然后在 GitHub Desktop：

1. Summary 填写 `Update to V9.0`
2. 点击 `Commit to main`
3. 点击 `Push origin`
4. Cloudflare Pages 会自动更新原网址
