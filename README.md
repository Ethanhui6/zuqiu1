# ⚽ 足球生涯模拟器 V11.0 终极重构版 (Football Career Simulator V11.0)

本项目是《足球生涯模拟器》的终极进化与 Bug 修复重构版本 V11.0。

## 🌟 V11.0 修复与进化亮点

### 1. 结算与逻辑不一致修复 (Bug Fixes)
- ✅ **国家队数据完全一致**：精准追踪国足出场次数，出场 >0 时显示“国足 N 场”及对应进球，未入选则显示“未进过国家队”，彻底消除旧版“出场2次但显示没进过国足”的矛盾。
- ✅ **俱乐部数量精准计算**：严格按实际代表服役过的球队统计 `clubList` 数量，不再虚算未上场/刚签下的过渡转会。
- ✅ **清白机制透明标注**：清白度（Innocence）数值与规则说明明确呈现，并在残酷/反腐调查模式中承担惩罚判定。
- ✅ **巅峰 OVR 显眼区分**：退役结算与个人卡片上清晰标注 **“巅峰 OVR: XX”**（例如 巅峰 OVR 75），而退役时受衰退影响的实际能力单独标示为 **“退役 OVR: 58”**，避免玩家误解。
- ✅ **荣誉分类解耦**：彻底区分 **“个人殊荣”**（金球奖、金靴奖、亚洲足球先生、年度最佳阵容）与 **“团队冠军”**（世界杯冠军、欧冠、顶级联赛冠军、足协杯）。
- ✅ **出身与位置数值透明化**：
  - 广东（灵动盘带/资金）、山东（身体/信任）、辽宁（速度/声望）、北京（声望/粉丝）、上海（传球/球探关注）明示初始加成。
  - 位置（ST, RW, LW, CAM, CM, CDM, CB, RB, LB）明示对进球率、助攻率、身价权重与防守影响。
- ✅ **两难抉择（决策无机械最优解）**：50+ 故事分支选项配置高收益高负面风险博弈，让玩家面临真正的策略抉择。
- ✅ **节奏与难度模式解耦**：
  - 节奏模式：**逐年（关键年决策） / 标准（逐月推进） / 电影（自动播放）**
  - 难度模式：**新星（简单） / 职业（标准） / 残酷（硬核反腐伤病）**

### 2. PWA 与社交分享增强
- ✅ 支持 PWA (`manifest.json` + `sw.js` + Apple Touch Icon)，可一键保存添加到手机桌面作为独立 App 运行。
- ✅ Open Graph 与 Twitter Card 社交分享元标签支持。
- ✅ 40 岁挂靴终极总结卡与图片导出分享。

### 3. 全新视觉建模与生活模拟 (3D & Life Simulation)
- ✅ **3D/Vector 球员模型**：支持肤色、发型、面部、装备（头带/护腕/球鞋）调节，随着年龄增长呈现老练胡须，负伤时呈现医用绷带。
- ✅ **2.5D 战术球场比赛引擎**：呈现天气系统（晴朗/暴雨/大雪）、期望进球 xG 统计、赛后 MVP 评选与比分演播。
- ✅ **3D 旋转荣耀展厅**：可旋转/透视查看个人殊荣与团队冠军奖杯。
- ✅ **跨洲际职业足迹地图 (Global Career Map)**：转会履历路线图与航线呈现。
- ✅ **房产与豪车奢华生活 (Life & Property System)**：市区公寓 $\rightarrow$ 高档大平层 $\rightarrow$ 独栋别墅 $\rightarrow$ 顶奢庄园，配套保时捷/法拉利超跑座驾与车库。
- ✅ **100+ 真实球队数据库**：涵盖英超、西甲、德甲、意甲、法甲、中超、J联赛、K联赛、MLS、沙特联等 S~D 级球队。

## 🚀 GitHub 上传与 Cloudflare Pages 部署教程

本项目为纯静态单页应用（SPA）架构，**不依赖 Node/npm 命令行编译**，可直接上传至 GitHub 并由 Cloudflare Pages 自动部署。

### 1. 更新 GitHub 仓库

解压下载的压缩包，将其中的所有文件拷贝覆盖到你的原 GitHub 仓库目录（如 `Ethanhui6/zuqiu1`）：

```bash
git add .
git commit -m "feat: 升级足球生涯模拟器 V11.0 终极重构版 (修复结算矛盾+PWA+2.5D比赛+3D荣誉展厅+豪宅座驾)"
git push origin main
```

### 2. Cloudflare Pages 自动构建配置

在 Cloudflare Pages 控制台中：
- **Build command（构建命令）**：留空（None）
- **Build output directory（输出目录）**：`/` 或 `. `（根目录）

Push 成功后，Cloudflare Pages 会在 10 秒内自动构建并发布覆盖，保持原 `pages.dev` 网址不变并升至 V11.0！
