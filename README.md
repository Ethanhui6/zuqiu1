# ⚽ 足球生涯模拟器 V13.0 Apple iOS 极简重构版 (Football Career Simulator V13.0)

本项目是《足球生涯模拟器》的全面极简重构版本 V13.0。

## 🍎 V13.0 重构亮点

1. **Apple iOS 极简设计语言**：
   * 采用深黑背景（#000000）、高透明度毛玻璃（`backdrop-filter: blur(30px)`）、SF Pro 字体与极简 iOS 卡片风格，去除页面杂乱冗余文字。
2. **多步骤角色建模与捏脸向导 (Multi-Step Wizard)**：
   * 开局完整还原选人流程：姓名、惯用脚、球衣号码、Seed 随机种子、出生地特质（明示加成）、球场位置与 Roguelike 初始天赋抽卡。
3. **完美融合三大参考网站核心优点**：
   * **绿茵浮沉版**：中国足球现实生态叙事（反腐调查、更衣室派系、新闻发布会交互、懂球圈社交热搜）。
   * **足一把版**：离线 Seed 种子系统、47+ 成就图鉴墙、四大核心属性联动与分享卡片。
   * **重生版**：Roguelike 初始天赋抽卡（金/紫/蓝品质）、退役后“第二人生”（转型主教练/解说员/投资人/青训总监）。
4. **完全修复 8 处数据矛盾与缺陷**：
   * 国足出场统计与“未进国足”精准统一。
   * 俱乐部数量按实际服役队数精算 `clubList`。
   * 清白度（Innocence）数值与规则显隐说明。
   * 巅峰 OVR 显眼区分（如“巅峰 OVR: 75” 与“退役 OVR: 58”）。
   * 个人殊荣（金球奖/金靴）与团队冠军（世界杯/欧冠）解耦拆分。
   * 两难抉择博弈，消除机械最优解。
5. **PWA Standalone 支持**：
   * 内置 `manifest.json` 与 Service Worker，可一键保存添加到手机桌面作为独立 iOS App 运行。

## 🚀 GitHub & Cloudflare Pages 部署教程

解压下载的压缩包，将其中的所有文件覆盖到你的原 GitHub 仓库目录（如 `Ethanhui6/zuqiu1`）：

```bash
git add .
git commit -m "feat: 重构升级足球生涯模拟器 V13.0 iOS极简版 (开局捏脸向导+三站精华融合+懂球圈+退役二次人生)"
git push origin main
```

Cloudflare Pages 会在数秒内自动构建发布，原网址保持不变并直接升至 V13.0！
