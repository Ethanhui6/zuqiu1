# 绿茵浮沉 8.0（大型重构版）

## 核心变化
- Apple 标准应用式 UI（不是 Apple Sports 风格），页面保持单屏主任务 + 二级菜单
- 306 家真实俱乐部、38 个联赛与级别
- 中文队名 + 当地官方语言名称
- 76 名精选现实球员，含 FC 26 风格六维数据、现实照片解析与荣誉记录
- 3600 个事件组合；每个存档记录已发生事件，同一组合不会在该生涯重复
- 比赛完全自动模拟，玩家只面对职业人生、关系和关键决定
- 真实出场顺位：青年队、预备队、未进名单、替补、轮换、主力、核心
- 租借、自由转会、合同到期、国家队、奖项与退役永久档案
- 创建球员采用种子系统；真人照片优先、48 张本地后备头像
- 12 张球场环境、10 个高分辨率奖杯后备模型和 8 张 UI 纹理

## 部署
Cloudflare Pages Direct Upload：上传 `football-career-reborn-v8-deploy.zip`，保持 `index.html` 位于根目录。

Cloudflare Pages 单个静态资源限制为 25 MiB；本包总容量超过 50 MB，但所有单个资源均低于限制。

## 联网图片
现实球员照片、真实队徽和奖杯优先通过 Wikipedia/Wikimedia 加载；创建球员优先通过 Random User Generator 加载真人测试头像。远程加载失败时均有本地后备。
