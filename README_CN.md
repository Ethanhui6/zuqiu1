# 绿茵浮沉 V18.3

一个无需构建工具、可以直接部署到 Cloudflare Pages 或 GitHub Pages 的足球球员职业生涯 Roguelike 模拟器。

## V18.3 核心循环

创建球员后先选择职业节奏，再通过阶段目标、自动策略和时间推进管理完整生涯：

```text
选择目标 → 设置训练与比赛策略 → 推进时间 → 处理关键比赛或事件
→ 查看阶段总结 → 调整职业方向 → 进入下一阶段
```

游戏提供四种职业节奏：沉浸、标准、快速、传奇速通。游戏内永久显示暂停、1倍、2倍、4倍和快速推进控制，并支持推进至下一事件、下一场比赛、一周、一个月、转会窗口或赛季结束。

普通训练和普通比赛可以自动结算；转会报价、合同谈判、首次首发、重要比赛、决赛、伤病、国家队征召、教练谈话、传奇事件和重大职业转折可分别设置自动暂停。

## 主要玩法

- 16—18岁从真实俱乐部青年梯队开始
- 六步创建流程：身份、球场位置、风格、天赋、青年队邀请、职业节奏
- 每赛季选择最多两个阶段目标，目标会改变训练建议、事件权重和奖励
- 自动训练、比赛和职业策略可随时修改
- 40周确定性赛程，区分青年联赛、预备队、国内联赛、杯赛、友谊赛、季前赛、洲际比赛和国家队比赛
- 比赛支持一键结果、快速时间线和互动比赛三种呈现
- 事件根据年龄、阶段、球队、最近标签、选择结构、剧情链和冷却筛选，显示2—5个真实差异选项
- 夏季与冬季转会窗口由玩家决定接受、拒绝、暂缓、谈判、租借或留队
- 能力、体能、士气、教练信任、粉丝、关系、合同、国家队、荣誉和结局长期联动

## 内容规模

- 500家俱乐部身份记录
- 500条成长模板记录
- 330项成就
- 1,200个基础事件记录、6,000条选择、20个新增连续剧情节点
- 11个场上位置与门将独立能力标签
- 12种训练计划
- 4种职业节奏、5档推进速度、6种推进目标

## 运行

项目是原生静态网页。请使用本地静态服务器运行：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 测试

测试包含核心玩法、完整生涯、存档迁移、转会边界、事件重复、节奏与推进、20赛季自动模拟、静态检查和320/375/390/430像素移动端几何审计。

## 数据说明

俱乐部身份、成长模板名称和原始事件数据继承自用户提供的项目。球队实力、进攻、防守、青训、财政、球迷和战术为本游戏独立模拟值，不是 EA Sports FC、国际足联、联赛或俱乐部官方评级。详见 `docs/V18_DATA_SOURCES.md`。
