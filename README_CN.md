# 绿茵浮沉 V18.1

一个无需构建工具、可以直接部署到 Cloudflare Pages / GitHub Pages 的足球球员职业生涯 随机选择 模拟器。

## 主要玩法

- 16—18 岁从真实俱乐部青年梯队开始
- 五步创建流程：身份、球场位置、风格、天赋、青年队邀请
- 每个阶段自动结算训练，再进入职业事件和关键比赛
- 事件根据年龄、阶段、最近标签、剧情链和冷却筛选，显示 2—5 个方案
- 比赛根据球队实力、位置、体能、士气、教练信任、天气和主客场生成
- 夏季与冬季转会窗口，由玩家决定接受、拒绝、暂缓或谈判
- 能力、粉丝、社交关注、商业价值、关系、合同、国家队、荣誉与结局长期联动

## 内容规模

- 500 家俱乐部身份记录
- 500 条成长模板记录（100个不同模板名称的成长变体）
- 330 项成就
- 1,200 个事件记录、6,000 条选择、3,215 条不重复选择文本
- 11 个场上位置与门将独立能力标签
- 12 种训练计划
- 多种球队冠军、位置奖项和职业结局

## 运行

项目是原生静态网页。不能直接双击 `index.html`，因为浏览器通常会阻止本地 JSON 模块请求。请使用本地静态服务器：

```bash
python -m http.server 8080
```

然后访问：

```text
http://localhost:8080
```

## 测试

需要 Node.js 18 或更新版本：

```bash
npm test
node tests/career-sim.mjs
node tests/acceptance-tests.mjs
node tests/runtime-audit.mjs
node tests/static-check.mjs
```

## 数据说明

俱乐部身份、模板名称和原始事件数据继承自用户提供的 V18 项目。球队实力、进攻、防守、青训、财政、球迷和战术等数值为本游戏独立模拟值，不是 EA Sports FC 或任何联赛的官方评级。详见 `docs/V18_DATA_SOURCES.md`。
