# 绿茵浮沉 V18｜肉鸽生涯重构版

这是一个无需安装依赖、无需构建、可直接部署到 Cloudflare Pages 的静态网页游戏。

## V18 核心内容

- 单局约 8—10 分钟，从 16 岁青年队开始，经历青训、突破、成长、巅峰、衰退和退役。
- 640 个独立事件场景，20 个事件类别。
- 每个事件固定 5 个不同选择，共 3,200 条不重复选择文本。
- 每个赛季重新抽取：生涯路线、五项抉择、比赛关键时刻、概率判定和转会窗口。
- 12 条肉鸽路线、增益特性、负面状态和隐藏事件链。
- 330 项成就，其中 50 项为隐藏成就或隐藏结局。
- 500 个低概率传奇模板：100 位真实球员风格原型，每位有 5 条不同成长支线。
- 500 家真实俱乐部，覆盖 47 个联赛/赛事层级；球队强度为本游戏独立估算。
- 每赛季一次转会窗口，玩家自行选择留队或接受报价，不会自动转会。
- 原创浅色 iOS 风界面、毛玻璃导航、盾形能力卡和中文六边形能力图。
- 不使用球员照片，所有可见界面以中文为主。
- 本地浏览器自动保存存档。

## 直接覆盖原网站

1. 解压 `football-career-v18.0-replace.zip`。
2. 打开 GitHub Desktop。
3. 点击 `Repository → Show in Explorer`。
4. 打开仓库根目录，也就是能直接看到 `.git`、`index.html` 的文件夹。
5. 把压缩包内的全部文件和 `data` 文件夹复制进去。
6. 出现提示时选择“替换目标中的文件”。
7. 不要删除隐藏的 `.git` 文件夹。
8. 回到 GitHub Desktop，提交说明填写：`Update game to V18`。
9. 点击 `Commit to main`，然后点击 `Push origin`。
10. Cloudflare Pages 会在同一个项目和同一个正式域名上更新。

## 避免每次出现新网址

Cloudflare 每次部署都会生成一个带哈希的预览地址，例如：

`69f7555b.项目名.pages.dev`

这不是新的正式网站。请长期使用不带前缀哈希的生产地址，例如：

`项目名.pages.dev`

只要 GitHub 仓库和 Cloudflare Pages 项目没有重新创建，正式地址不会改变。

## 旧版本缓存

V18 已加入旧 Service Worker 和缓存清理逻辑，专门处理“代码已经更新，手机仍显示 V8/V10”的问题。首次打开新版后建议刷新一次；仍显示旧版时，在网址末尾临时加：

`?v=18`

## 文件说明

- `index.html`：网页入口。
- `styles.css`：完整浅色 iOS 风样式。
- `app.js`：生涯、事件、成长、比赛、转会、成就和存档引擎。
- `data/clubs.json`：500 家俱乐部。
- `data/legend-templates.json`：500 个传奇成长模板。
- `data/events/`：20 类事件、640 个场景、3,200 个不同选择。
- `data/achievements.json`：330 项成就与隐藏结局。
- `sw.js`：清理旧版本遗留缓存，不创建新的离线缓存。

## 数据与素材说明

本项目没有复制 EA SPORTS FC 的官方卡面、球员照片、俱乐部徽标或完整专有评分数据库。六项能力结构与球员风格原型用于独立单机模拟；俱乐部强度、潜力、成长和转会适配均为本游戏自行计算。
