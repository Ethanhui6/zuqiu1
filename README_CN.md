# 绿茵浮沉 V18.5

一个无需构建工具、可直接部署到 Cloudflare Pages 或其他静态主机的足球球员职业生涯模拟器。V18.5 的重点是移动端优先架构：修复日期控件、点击遮挡、卡片重叠、底部导航遮挡、Safari 动态视口和旧缓存。

## V18.5 移动端结构

```text
AppShell
├── AppHeader
├── PageContainer（唯一主要纵向滚动容器）
├── SpeedDock
└── MobileBottomNav
```

手机底部导航固定为：生涯、比赛、训练、转会、更多。球队世界、个人资料、成就和设置从“更多”进入。

## 创建球员

创建流程为六步单任务向导：

1. 基础身份和原生生日输入
2. 身体与国籍
3. 球场位置
4. 球员风格
5. 天赋报告
6. 青年队与职业节奏

生日保存为 `YYYY-MM-DD` 纯日期字符串，不经过 UTC 转换。输入草稿自动保留，主操作按钮始终位于可见区域。

## 主要玩法

- 16—18岁从青年梯队开始
- 四种职业节奏和五档推进速度
- 按事件、比赛、周、月、窗口或赛季推进
- 训练、比赛、事件、转会、合同、粉丝、关系、荣誉和结局长期联动
- 500家俱乐部身份记录、500条成长模板、330项成就
- 确定性随机与多存档、导入导出、旧存档迁移

## 运行

```bash
python -m http.server 8080
```

访问 `http://localhost:8080`。开发环境会注销旧 Service Worker，避免缓存旧 UI。

## 数据与队徽说明

俱乐部身份来自项目原有数据。球队能力、财政、青训和战术是游戏模拟值，不是官方评级。队徽组件只加载安全的本地资源；没有本地资源时使用统一盾牌占位，没有用字母缩写冒充真实队徽。

## 本版本边界

V18.5 按当前阶段要求没有新增世界排行榜、服务器权威验证、反作弊后端或新的大型动画系统；本轮只交付移动端可用性和全局 UI 架构修复。
