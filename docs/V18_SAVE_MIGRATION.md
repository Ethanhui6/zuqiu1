# V18.1 存档与迁移说明

## 新存档

- 存档Schema：18
- 支持3个存档槽
- 每次真实状态更新后同步自动保存，避免点击后立即刷新丢失结果
- 保存前生成校验和，并保留上一份有效备份
- 保存随机种子、随机状态、事件、比赛、报价、设施冷却和延迟后果
- 支持手动保存、导入、导出、删除和损坏恢复

## 兼容键

迁移器会检查：

- `green-pitch-career-v18`
- `football-career-save`
- `career-sim-save`
- `zuqiu-save`
- `footballCareerSave`
- `green-pitch-save`

旧字段会映射到V18.1的球员、生涯、状态、关系、粉丝、财务、设施、合同和成就结构。无法恢复的字段使用中性默认值，并写入 `meta.migrationNotes`，不会静默删除旧档。

## 同Schema早期构建

即使旧存档已标记Schema 18，`normalizeSave()` 仍会补齐：

- 事件标题和选择结构记忆
- 延迟后果及剧情链
- 报价历史、转会窗口锁和租借状态
- 设施访问与阶段冷却
- 粉丝历史和多维关系
- 赛季荣誉、合同、财务和随机状态

已有球员属性、俱乐部、比赛纪录和荣誉不会被默认值覆盖。

## 损坏和导入边界

- 主存档JSON损坏或校验失败时，会尝试恢复有效备份。
- 无校验的早期存档允许迁移，迁移后会重新签名。
- 导入文件会校验大小、JSON格式、完整性和核心可玩字段。
- 校验伪造、结构损坏或无法迁移的文件会显示错误，不会覆盖现有存档。
