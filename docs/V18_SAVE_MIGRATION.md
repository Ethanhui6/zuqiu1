# V18 存档与迁移说明

## 新存档

- 存档 Schema：18
- 支持 3 个存档槽
- 每次状态更新后延迟自动保存
- 保存前生成校验和，并保留上一份备份
- 保存随机种子、当前随机状态、事件、比赛和报价，因此刷新页面不会重新抽取结果

## 兼容键

迁移器会检查：

- `green-pitch-career-v18`
- `football-career-save`
- `career-sim-save`

旧字段会映射到 V18 的球员、生涯、状态、关系、粉丝、财务和成就结构。无法恢复的关系与隐藏属性使用中性默认值，并写入迁移备注。

## 同版本早期构建

即使旧存档已经标记 Schema 18，`normalizeSave()` 仍会补齐新增字段，例如：

- 事件记忆
- 延迟后果
- 比赛纪录
- 粉丝历史
- 关系维度
- 赛季荣誉
- 合同和财务默认值

不会覆盖已有比赛数据、球员属性、俱乐部和荣誉。
