# 《绿茵浮沉》重构总计划

最后更新：2026-08-03

## 产品与工程原则

- 保留现有职业、比赛、训练、转会、合同、事件、成就和存档规则，不以静态页面替代真实逻辑。
- 默认面向 320–430px 手机；单列、全宽卡片、一页一个核心任务，不缩放桌面页面，不依赖 hover、鼠标滚轮或拖拽。
- AppShell 唯一管理顶部栏、动态视口、正文滚动、速度栏、五入口导航、安全区、弹层和 Toast。
- UI 使用统一 iOS 浅色令牌；页面不能自行建立互不兼容的主题。
- 游戏随机只经过带种子的随机服务；关键业务不得直接调用 `Math.random()`。
- UI、游戏系统、数据、存档、本地化、动画、计分和联网服务分层；正式界面不显示内部英文 key。
- 旧代码先进入 `legacy/` 作为迁移参考，替代验证完成前不清理。
- 世界榜不接受客户端自报总分；服务端验证证据和检查点，再按统一规则计算。

## 当前架构

- `src/app/`：版本、路由、状态容器和应用配置。
- `src/components/appShell.js`：AppHeader、MainViewport、BottomNavigation、OverlayRoot、ToastRoot。
- `src/components/`：无业务数据所有权的卡片、弹层、Toast、队徽等组件。
- `src/pages/`：建档、生涯、比赛、训练、转会、球队世界、档案、更多和排行榜。
- `src/systems/career/`：职业状态、六种时间推进、重要节点暂停和赛季结算。
- `src/systems/event/`：条件事件、结果组合、防重复、剧情链及延迟/隐藏后果。
- `src/systems/schedule/`：八类赛事、赛程、梯队、资格和模拟升降级。
- `src/systems/match/`、`training/`、`transfer/`、`contract/`：各业务状态机。
- `src/services/`：数据仓库、存档迁移、带种子随机、本地排行榜和联网 API。
- `src/utils/format.js`：中文日期、金额、百分比、属性和效果统一格式化。
- `src/animations/`：统一动画导演、注册表和减少动态效果适配。
- `server/`、`functions/`：排行榜服务、反作弊校验、D1 仓库和 Worker/Pages API。
- `tests/`：规则、长生涯、游戏深度、静态/UI、真实 Chromium、后端和 Worker 测试。

## 游戏深度实现边界

### 职业节奏

- 开局和设置均可选择沉浸、标准、快速、传奇速通。
- 存档保存暂停、1 倍、2 倍、4 倍和快速推进。
- 支持下一事件、下一场比赛、推进一周、一个月、转会窗口和赛季结束。
- 首次首发、重大比赛、伤病、报价、合同、国家队、传奇事件、决赛和退役决定会暂停；普通内容按策略自动结算。

### 事件组合与防重复

- 活动数据为 1120 个模板、5600 个选择、12800 种有效结果组合，超过 3000 组合目标，但不以重复文本数量冒充内容质量。
- 条件涵盖年龄、位置、能力、潜力、球队、梯队、联赛、赛季阶段、近期表现、体能、士气、信任、关系、合同、转会意愿、职业目标和历史选择。
- 选择数为 2–5；每项至少影响两个系统，可附带即时、延迟、隐藏、剧情链、成就或结局倾向。
- 最近 20 个标签、事件 ID、选择结构、冷却、唯一事件、剧情链、人物和对手均写入存档。

### 赛事、球队与转会

- 500 家球队覆盖 37 国、47 联赛；球队身份信息与独立模拟评分分开标记，不复制 FIFA/FC 专有数值。
- 八类赛事按国家、层级、梯队和资格生成，模拟升降级和洲际资格随赛季结算。
- 夏窗和冬窗按状态机处理；玩家显式接受之前绝不改变 `clubId`。
- 官方队徽资源未包含在压缩包内；只有取得可分发授权后才接入真实徽标，当前统一盾牌占位不冒充已完成。

## 计分与反作弊边界

当前服务端会：

1. 为新生涯签发运行会话，旧存档仅进入本地榜。
2. 接收有序检查点，验证身份不可变、时间跨度和能力/数据/奖杯/成就增量。
3. 校验证据摘要，只接受最后一个有效检查点。
4. 使用共享计分规则在服务器重新计算总分和等级。
5. 世界榜只查询 `verified=1` 的记录。

这属于服务器权威计分与基础反作弊，不等同于完整确定性重放；完整重放保留在 `v18.9.0`。

## 验收门槛

- `npm test`：规则、存档迁移、事件组合、防重复、节奏、赛程、转会、后端和 Worker 全通过。
- `npm run test:20`：至少 20 赛季，输出比赛/对手/事件/重复率/转会/剧情链/成就/结局/耗时/控制台错误。
- `npm run test:mobile`：320×568、375×667、390×844、430×932、768×1024、1440×900 真实 Chromium 通过完整关键流程。
- 每个移动视口验证可见、可点击、无横向溢出、无竖排或关键重叠、无透明遮罩、无重大控制台错误。
- `npm run build`：生成前端、Worker 和 D1 迁移，构建不得混入 `legacy/`。
- 部署前必须再次运行 `npm run test:all`，再在部署地址做浏览器可见性与交互复核。

## 明确不做

- 不复制 FIFA/FC 专有数据库、数值或未经授权的队徽。
- 不用 GIF、视频、`zoom`、桌面布局缩放或大面积绝对定位替代真实交互。
- 不用静态数据伪造排行榜、转会、赛程或事件。
- 不宣称桌面 Chromium 等同于实体 iPhone/Android 测试。
- 不宣称检查点反作弊已经等于服务器完整重放。
