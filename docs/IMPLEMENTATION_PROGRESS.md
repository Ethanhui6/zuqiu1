## 本轮关键修复

- 修复连续切换Bottom Sheet时共享清理计时器导致旧遮罩永久残留的问题；每个关闭中的Sheet现在拥有独立回收生命周期。
- 修复赛程重排后下一场比赛可能不是最早日期的问题。
- 修复原生DOM直接追加空值时页面出现字面量“null”的问题。
- 修复训练事件选择按钮高度不足44像素的问题。
- 修复更多页面消息中心仍是说明入口的问题，改为真实未读消息列表与已读操作。
- 修复世界探索测试和页面组件类名不一致导致无法完成四级浏览的问题。

## 仍需外部条件

- 实体iPhone Safari、Android真机和低端机性能需要在真实设备上补充最终验证。
- 项目未附带500家俱乐部的可分发授权队徽包，缺失资源时使用统一原创盾牌占位。
