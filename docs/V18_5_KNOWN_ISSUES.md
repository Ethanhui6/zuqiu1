# V18.5 已知限制

1. 当前环境无法完成实体 iPhone Safari、iOS Chrome 和 Android 真机测试；已完成多视口 Chromium 几何与交互审计，并明确区分两者。
2. 原生 `input[type=date]` 的系统弹层样式由 iOS/Android 浏览器决定，项目只控制字段、数值范围、纯日期保存和关闭后的页面状态。
3. 500 家俱乐部并未全部绑定已核验的本地真实队徽。已有安全本地资源时显示资源，否则使用统一盾牌占位；没有用字母块冒充正式队徽。
4. 本版本没有实现世界排行榜、服务器权威验证或反作弊后端，因为当前阶段指令明确要求先停止新增排行榜和玩法，完成移动端可用性修复。
5. 源码包保留早期 CSS 作为历史材料，但生产入口只导入 V18.5 样式链。
