# V18.1 已知限制与未完成事项

1. 500家俱乐部名称记录来自项目内置数据库，本次离线环境没有逐条核验2026年的最新联赛归属。球队实力、财政、青训、球迷、城市、球场容量和战术均为游戏模拟字段，不是官方或实时数据。
2. 成长模板共500条独立ID，但只有100个不同模板名称；其余为成长路线和位置变体。不能表述为500位完全不同的现实传奇球员。
3. 事件库有1,200条记录、719个不同标题和3,215条不同选择文本。系统通过存档、位置、年龄、球队、关系、结果和延迟后果形成超过3,000种有效状态组合，但不是3,000篇完全独立手写剧情。
4. 没有内置EA Sports FC官方评分、卡图、商标或未经授权的真实球员照片。
5. 比赛属于事件驱动的生涯模拟，不是完整11对11实时足球引擎；每阶段重点展示一个关键节点。
6. 国家队采用阶段性征召和大赛结算，没有完整独立赛程与所有国家队数据库。
7. 合同谈判已覆盖工资、定位、租借和解约金等主要操作，但没有任意编辑每一项奖金的自由表单。
8. 已建立简体中文语言字典，主要界面均为中文；部分事件正文仍直接存放在中文数据文件中，未来扩展其他语言需要继续迁移语言键。
9. 当前执行环境中的Chromium被组织策略禁止访问本地和私网地址，无法完成自动截图及真实移动浏览器回归。响应式CSS、路由滚动和DOM逻辑已自动测试，但仍需在实际iPhone、Android和Safari中最终确认。
10. 静态PWA适合单机和小规模部署；存档只存在当前浏览器本地，清除浏览器网站数据前应先导出备份。
