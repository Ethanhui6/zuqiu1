## 浏览器环境限制

当前执行环境的安全策略会阻止 Chromium 导航到本地 HTTP 与 `file:` URL，因此移动审计使用 Playwright `set_content`，加载项目生产 CSS 和与实际组件一致的 DOM 类结构进行几何、点击、弹窗与滚动测试。没有把这项测试冒充为实体 iPhone Safari 真机测试，也没有声称验证了 Safari 原生日期选择器的系统弹层外观。
