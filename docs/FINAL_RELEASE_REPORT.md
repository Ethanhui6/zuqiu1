- 从设备所有存档实时计算；离线存档可进入。

- 支持位置、退役、认证筛选及评分、最后游玩、出场、能力排序。

## 14. 世界排行榜

- 支持总榜、本周、本月、当前赛季、历史、位置及特殊路线分类；分页上限100条。
- API支持附近排名、本人记录、版本、难度、位置过滤；UI完成分类、分页和公开摘要。
- 修改公开昵称、隐藏详情、撤回排名和举报异常成绩均有服务端接口；认证后可在排行页调整公开信息。

## 15. 服务器验证

- `/api/runs/start` 生成 `runId`、`serverSeed`、版本、初始状态、sessionToken和stateHash。
- `/api/runs/action` 服务端推进训练、比赛、事件、转会和赛季状态；客户端不能提交score、grade或rank。
- `/api/runs/checkpoint` 生成服务端快照；`/api/runs/finish` 重算评分、评级并发布。
- D1条件更新实现sequence/stateHash并发写入保护。

## 20. 已知限制

- **未完成：实体iPhone/iPad Safari人工验收。** 已完成Chromium移动触控与原生日期自动化，仍需发布方在真机核对系统日期面板外观。

- 未接入KV热门榜缓存或Durable Objects；当前D1条件更新已提供顺序状态和并发保护，流量上升后可增加缓存层。

## 21. 部署方法

1. `npm ci`
2. `npm test`
3. `npm run test:20 && npm run test:mobile`
4. `npm run build`
5. 部署 `dist/`；Worker入口为 `dist/server/index.js`，静态入口为 `dist/client/index.html`。
6. 绑定D1为 `DB`，依次执行 `.openai/drizzle/0000_leaderboard.sql`、`0001_authoritative_runs.sql`。
7. 环境变量参考 `.env.example`；前端不需要服务端密钥。
