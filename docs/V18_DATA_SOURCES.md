# V18.1 数据来源说明

## 俱乐部

`data/clubs.json` 中包含500家俱乐部身份记录，ID和中文名称均唯一。中文名、外文名、国家与联赛字段继承自用户提供的项目数据库。本轮在离线环境中没有逐队核验2026年的最新归属，因此：

- 身份字段不声明为实时官方名单；公开发布前应再次核对。
- 城市无法确认时标记为“未核实”。
- 综合实力、进攻、防守、青训、财政、声望、球迷规模、球场容量、战术、招募倾向、青年使用倾向和位置需求均为独立游戏模拟值。
- 模拟值不伪装成EA Sports FC、国际足联、联赛或俱乐部官方数据。

## 成长模板

`data/legend-templates.json` 含500条唯一ID记录，覆盖10个主要位置，每个位置50条；其中有100个不同模板名称，其余是成长路径和数值变体。

球星姓名只作为风格灵感标签。本项目没有附带官方卡图、真实球员照片或EA商标素材，也不声明数值等同于任何FC版本官方评分。

## 事件

- 事件记录：1,200条
- 不同标题：719个
- 原始候选选择：6,000条
- 不同选择文字：3,215条

运行时会结合年龄、位置、梯队、球队层级、关系、事件记忆、冷却、剧情链和随机状态，从每条事件的候选方案中确定性选出2—5项。数据规模不等同于1,200篇完全独立长篇剧情。

## 成就

成就共330项，其中50项为隐藏成就。解锁由比赛数据、赛季纪录、关系、转会、国家队和生涯状态判定，不使用随机数直接授予。

机器可读说明位于 `data/data-sources.json`。
