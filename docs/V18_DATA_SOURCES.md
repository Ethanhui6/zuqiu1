# V18 数据来源说明

## 俱乐部

`data/clubs.json` 中的俱乐部中文名、外文名、国家、联赛和层级继承自用户提供的 V18 项目数据。该版本没有联网逐队核验，因此：

- 身份字段不声明为最新官方名单；公开发布前应再次核对。
- 城市无法确认时明确写为“未核实”。
- 综合实力、进攻、防守、青训、财政、声望、球迷规模、球场容量、战术、招募倾向、青年使用倾向和位置需求均为独立模拟值。
- 这些模拟值不伪装为 EA Sports FC、国际足联、联赛或俱乐部官方数据。

## 成长模板

`data/legend-templates.json` 继承自用户提供的项目数据。球星姓名仅作为成长风格灵感标签；本项目没有附带官方球员卡图、真实球员照片或 EA 商标素材，也不声明数值等同于任何 FC 版本官方评分。

## 事件与成就

- 事件来源于用户项目分类数据与 V18 组合式扩展。
- 当前包含 1,200 个事件记录、6,000 条选择，其中 3,215 条选择文本不重复。
- 成就共 330 项，解锁由比赛数据、赛季纪录、关系、转会、国家队和生涯状态决定，不使用随机数直接授予。

机器可读说明位于 `data/data-sources.json`。
