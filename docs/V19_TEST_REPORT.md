## 测试环境限制

当前执行环境禁止浏览器直接访问 localhost，因此浏览器测试使用 Playwright 请求路由加载原始生产文件，而不是静态 HTML 假页面。Node 版 Playwright 依赖无法从当前私有 npm 镜像下载，移动端测试改由环境中已安装的 Python Playwright 与系统 Chromium 执行。

本报告不把上述测试描述成实体 iPhone Safari 真机测试。项目已经覆盖真实移动视口、触控模式、DOM 点击、滚动、Sheet 生命周期与重新装载，但实体 Safari 仍需要部署后在真实设备上进行最后一次验收。
