# V20 当前缺陷审计

审计日期：2026-08-03  
审计基线：V19.1 时间与职业AI版本  
修复版本：V20.0.0

## 已关闭问题

### 顶栏与首页
- 旧顶栏信息和操作拥挤：已由统一AppHeader处理玩家、球队、年龄、身价、节奏和保存。
- 首页卡片过高、信息重复：已拆为重点卡、人物卡、职业控制台和两张功能小卡。
- 首页不知道下一步：AttentionManager根据事件、比赛、报价、训练和目标生成真实重点。

### 长页面与空入口
- 数据分析、医疗、更衣室、荣誉室已从说明入口改为可操作系统。
- 训练页已加入推荐、方案、真实训练事件和结果反馈。
- 转会窗口关闭时已展示合同、市场关注、经纪人建议和潜在球队。
- 更多页消息中心已读取真实消息并支持标记已读。

### 世界与球队
- 世界页面不再以500支球队长列表为入口，改为本地SVG世界地图四级探索。
- 转会和世界页面共用球队详情、位置机会、合同预估、收藏、对比和目标状态。
- 赛程数组在任何去重重排后重新按日期排序；下一场比赛查询也强制排序。

### 本地化与数据渲染
- 生产流程未发现`[object Object]`、`undefined`、`null`、`NaN`、`World Explorer`、`Loading`或`Continue`。
- 修复直接`append(null)`在原生DOM中生成文字“null”的缺陷。
- 策略、状态、关系、比赛和金额通过中文格式化层输出。

### 弹层与点击
- 修复连续切换Sheet时旧遮罩清理计时器被新Sheet覆盖，导致透明层永久残留的问题。
- 每个关闭中的Sheet现在使用独立计时器，并在过渡完成或280ms兜底后释放。
- 训练事件选择卡已扩展为完整触控卡，最小高度52像素。
- 7档移动视口未发现透明遮挡、巨型黑绿层、小于44像素按钮或底栏覆盖。

### Service Worker与旧缓存
- 缓存版本：`green-pitch-v20.0.0-20260803-1`。
- 激活时清理旧缓存；HTML采用网络优先；新模块进入预缓存清单。
- 开发与自动化测试使用禁用Service Worker的隔离环境，避免误测旧文件。

## 尚未关闭的外部风险

- 自动化使用系统Chromium触摸模式，不能替代实体iPhone Safari的原生日期面板、软键盘和内存压力测试。
- 未提供全部俱乐部的可分发授权队徽资源，未知或缺失队徽使用统一原创盾牌。
- 世界地图是轻量足球区域探索图，不是精确行政边界地图。
