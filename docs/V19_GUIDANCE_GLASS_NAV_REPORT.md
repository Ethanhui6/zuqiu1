# V19 页面引导、玻璃底栏与节奏设置重构报告

## 版本

- 游戏版本：19.0.0
- 存档结构：21
- 基线源码：用户提供的《足球生涯模拟器》V18.9.0 GitHub 源码包
- 本轮范围：页面引导、待办提醒、滚动提示、iOS 玻璃底栏、节奏设置迁移和轻量动画生命周期

## 1. 常驻速度控制栏

原 AppShell 中的暂停、1倍、2倍、4倍和快速推进控制器已经从页面 DOM、AppShell 网格和底部留白计算中删除。生涯、比赛、训练、转会、世界与其他普通页面不会再渲染大型速度控制栏，也没有通过透明度或 `display` 状态保留旧控件。

速度统一迁移到“游戏节奏”Bottom Sheet：

- 暂停
- 1倍
- 2倍
- 4倍
- 极速推进
- 职业节奏模式
- 普通事件动画速度
- 自动推进普通训练
- 自动模拟普通比赛
- 重大事件及细分职业节点自动暂停

设置变更通过 Store 立即写入当前存档，同时写入 `green-pitch-v19-pace` 本机偏好；已有存档与新存档都会读取并补齐这些字段。普通页面只在右上角显示小型速度状态，点击后直接打开节奏 Sheet。

## 2. 下一步引导系统

新增 `src/systems/guidance/guidanceSystem.js`，根据真实游戏状态计算当前优先事项。优先级为：

1. 未解决关键事件
2. 未解决比赛
3. 未处理转会或合同报价
4. 本周未完成训练
5. 尚未选择的阶段目标
6. 下一场赛程
7. 推进至下一职业节点

引导条不是静态文案。它读取当前存档的 pending、weekState、objectives、offers 与赛程数据，点击后进入对应页面。

## 3. 未处理事项徽标

底部导航徽标连接真实状态：

- 生涯：关键事件与未选阶段目标
- 比赛：待处理比赛或已到比赛周的赛程
- 训练：本周尚未完成训练
- 转会：未终结的报价数量
- 更多：尚未通知的成就数量

徽标数量在 Store 更新后重新计算；数量增加时播放一次短促弹性进入动画。定时器在 AppShell 销毁时清理。

## 4. iOS 玻璃悬浮底栏

底栏改为固定悬浮玻璃结构：

- 五个主要入口：生涯、比赛、训练、转会、更多
- 半透明白色玻璃、28px 模糊与饱和度增强
- 轻微顶部高光和克制阴影
- 圆角悬浮外形，左右与底部安全区域自适应
- 当前入口使用独立玻璃胶囊高亮
- 每个入口拥有不小于 44×44px 的触控面积
- 页面正文预留统一底部空间，不被导航遮挡
- 键盘打开时隐藏底栏，避免遮挡输入

旧的普通网页式底栏样式和速度栏高度变量已移除。

## 5. 滚动提示

新增轻量“下方还有内容”提示：

- 只有正文实际存在剩余内容、页面位于顶部且当前路由尚未被滚动时才显示
- 点击后平滑推进约半屏
- 用户滚动后自动消失，本次路由不再重复打扰
- 路由变化后重新判断
- 横屏低高度设备自动关闭
- 不创建全屏遮罩，不阻止页面点击
- ResizeObserver、MutationObserver、滚动监听和动画帧在 AppShell 销毁时全部释放

## 6. 动画体验与生命周期

本轮没有增加大型玩法动画，而是完善已有轻量反馈：

- 引导内容变化：短促上移淡入
- 待办徽标增加：弹性进入并自动清理状态
- 底栏选中：图标抬升和玻璃胶囊过渡
- 滚动提示：位移淡入及箭头轻微呼吸
- 节奏分段按钮：按压、选中与状态同步
- 普通事件动画速度：接入统一 AnimationDirector，改变演出时长但不改变已确定结果
- `prefers-reduced-motion` 下关闭重复动画并缩短过渡

引导动画计时器、徽标定时器、滚动观察器和事件监听器均有明确销毁路径，避免透明层或动画状态残留。

## 7. 训练与自动推进边界

训练页新增真实“开始本周训练”操作，完成后写入 `weekState.trainingDone`。关闭“自动推进普通训练”时，时间推进会在训练节点真实暂停；关闭“自动模拟普通比赛”时，会在普通比赛前等待玩家选择。暂停状态会直接打开游戏节奏 Sheet，避免出现无法理解的静态提示。
