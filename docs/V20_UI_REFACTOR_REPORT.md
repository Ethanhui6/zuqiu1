# V20 产品结构重构报告

## 版本

- 游戏版本：20.0.0
- 存档结构：23
- 构建：20.0.0-20260803-1

## 实际实现

- 首页重构为真实职业控制中心：当前重点、人物卡、职业控制台、赛季目标、设施摘要和训练提醒。
- 数据分析读取比赛、能力、体能、信任和粉丝历史并绘制SVG趋势。
- 医疗中心提供多种恢复方案，处理费用、体能、疲劳、伤病和设施历史。
- 更衣室提供关系行动，处理周冷却、信任、尊重、竞争和队内顺位。
- 荣誉室读取奖杯、成就、纪录和代表比赛。
- 训练页面连接智能推荐、当前策略、训练方案、训练事件和手动结算。
- 转会窗口关闭和开启状态均有真实内容；球队详情可收藏、对比、设置转会目标并提交意向。
- 足球世界使用本地SVG地图逐级浏览大洲、国家、联赛和球队。
- 更多页集中世界、设施、消息、存档、动画、声音、隐私和更新信息。
- 赛后页面改为四张摘要卡，根据位置显示不同个人表现指标。
- AttentionManager统一计算底栏角标、首页重点和设施待办，已读状态持久化。

## 关键技术修复

- Bottom Sheet关闭生命周期由共享计时器改为实例独立计时器，避免快速切换造成永久遮罩。
- 所有赛程读取与下一场比赛查询按日期排序。
- 生产页面不使用整页`innerHTML`重建。
- V20新增状态通过迁移模块补齐，不删除旧职业、比赛、合同、荣誉和转会数据。
