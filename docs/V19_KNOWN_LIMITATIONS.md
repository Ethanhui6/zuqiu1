# V19 已知限制

- 本轮基于用户上传的真实源码包完成修改，但压缩包不包含 `.git` 目录和远程仓库写入凭证，因此没有直接推送到 GitHub。
- 当前运行环境无法进行实体 iPhone Safari 真机操作；移动测试使用系统 Chromium、触控模式和多组真实视口完成。
- 执行环境阻止浏览器访问 localhost，测试通过请求路由加载项目原始生产模块。它不是静态假页面，但不能完全替代部署后的网络栈。
- 当前私有 npm 镜像无法下载 Node Playwright，因此仓库原有 Node 浏览器测试在本环境不能直接执行；本轮新增的移动浏览器测试由已安装的 Python Playwright 完成。
- 本轮没有扩展球队、事件或其他大型玩法；只处理用户指定的引导、导航、提醒、滚动、节奏设置和动画生命周期。
