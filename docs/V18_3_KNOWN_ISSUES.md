# V18.3 已知限制

1. **真机测试**：已完成320、375、390、430像素宽度的Playwright几何、滚动与点击审计，但未在实体iPhone Safari和Android Chrome上执行回归。
2. **完整浏览器自动化**：当前运行环境会拦截Chromium访问本地HTTP服务，因此没有完成从新建存档到退役的整站浏览器点击脚本；核心玩法通过Node状态测试完成。
3. **现实赛制精度**：赛程按国家、联赛、梯队、杯赛和洲际资格生成，但不是500家俱乐部每项官方赛制的实时镜像。
4. **国家队赛程**：国家队征召和比赛已经进入状态与赛程系统，但国家队仍使用简化赛历，没有独立完整预选赛分组。
5. **开局时间指标**：创建流程已压缩并在创建后立即触发职业钩子，但60秒、3分钟和5分钟指标尚未经过真人可用性计时。
6. **速度倍率含义**：1倍、2倍和4倍主要控制自动推进动画间隔；游戏状态仍按周顺序确定性结算，不会跳过必要状态更新。
