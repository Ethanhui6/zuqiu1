# V20 移动端产品结构重构计划与完成状态

## 目标结构

- `AppShell`：统一顶部栏、正文、玻璃底栏、Overlay与Toast。
- `careerPage`：首屏只保留当前重点、人物卡、职业控制台、赛季目标、设施摘要和训练提醒。
- `facilityCenterSheet`：数据分析、医疗、更衣室、荣誉室共用详情容器。
- `trainingPage`：训练摘要、教练建议、优先方案、更多训练和训练事件。
- `transferPage`：关闭窗口与开启窗口均提供真实可操作内容。
- `worldPage`：本地SVG地图四级探索，球队详情与转会共用。
- `morePage`：分组设置、存档、设施、消息与世界入口。
- `matchPage`：赛后四摘要卡和位置化统计。

## 设计约束

- 默认面向320至430像素手机宽度，平板与桌面使用`min-width`增强。
- 主要按钮与选择卡触控区域不小于44×44像素。
- 主页面避免整页重建，局部区域使用节点替换与事件委托。
- 动画只使用轻量位移、缩放和透明度，装饰层不参与点击。
- 详情信息进入统一Bottom Sheet；关闭后必须释放遮罩、滚动锁、监听器与焦点。
- 中文界面通过格式化层输出，禁止对象、内部键和无效数值直出。

## 已完成

全部目标模块已写入真实项目并连接当前存档。移动端端到端流程已经覆盖建档、首页、目标、设施、医疗、更衣室、训练、转会、球队详情、更多、消息、世界探索、比赛和刷新恢复。
